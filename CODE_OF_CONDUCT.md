# Code of Conduct

## Our standards

Everyone taking part in this project, in issues, pull requests, reviews, discussions and any other project space, is
expected to:

- be respectful and considerate, and assume good intent;
- critique ideas and code, never people;
- accept that maintainers decide what the project includes;
- never harass, threaten or demean anyone, or publish anyone's private information.

## Scope

This code applies in all project spaces, and when someone represents the project in public.

## Reporting

Report unacceptable behavior privately to the maintainer, Justin Samuel, at jsamuel12@gmail.com. Reports are kept
confidential as far as the law allows.

## Enforcement

The maintainer reviews every report and may, depending on its severity, give a warning, edit or remove comments,
commits and other contributions, or exclude a person from the project temporarily or permanently.
