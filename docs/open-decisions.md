| OD-29 | Runtime tests see no `/sys` (found 2026-10-24, `spikes/e2e-providers.md`) | **Decided (owner, 2026-10-26): give the runtime-test container a read-only view of its own cgroup**, with no host cgroup write access and nothing beyond that cgroup. **Not implementable in the current runtime test step (2026-10-26):** rootless BuildKit v0.34.0 strips every `/sys` mount and the step's cgroup path, and the step has no `CAP_SYS_ADMIN` under a seccomp profile that refuses `mount`, `unshare` and namespace-creating `clone`, so neither a mount nor a private namespace is possible; only `--security=insecure` changes that, which the decision excludes. | OD-28 | The local worker of a single server converted to a cluster's first controller | **Decided (owner, 2026-10-23): keep it, updated together with its controller.** `install.sh --role controller --keep-local-worker` (passed by `topology convert --to cluster`, kept in `/etc/samuori/install-args`) installs and upgrades the worker parts too; the controller keeps `localWorker.dir`. A rollout drains that worker, updates the host in its controller's step, then requires the worker's self-test; a failed self-test rolls the host back. Removing the controller drains and revokes the worker; the wipe deletes it | ADR 0046 (amended), `operators/high-availability.md#convert-between-a-single-server-and-a-cluster`, `operators/upgrades.md#self-update` |
| OD-27 | Rejecting a removed controller's NATS certificates | **Decided (owner, 2026-10-23): option 1.** Every member's routes hold exactly the current members, rewritten on join and on removal, and route TLS uses `verify_cert_and_check_known_urls`, so a peer whose name is not in the routes is refused even with a certificate the cluster CA signed. The rewrite is atomic per member, idempotent and retried, and never leaves a member without a peer; existing installs fill their routes before verification turns on. Remaining: members named by IP address cannot be checked, and an unwiped host still holds the database credentials and cluster key. CA rotation (option 2) was not chosen | ADR 0045 (amended), `operators/high-availability.md#nats-routes`, spike `nats-member-removal.md` |
| OD-25 | Signature timing and storage | **Approved with conditions (owner, 2026-10-20).** Sign on the controller at publication, binding the digest and destination repository. Use OCI 1.1 referrers where the registry supports them, and Cosign legacy tags always, for compatibility. Verify after publication; require a verified source signature before promotion; carry signatures and attestations on promotion; never trust unsigned or unverifiable images silently; keep private keys out of workers, logs and API responses; keep external key providers (WP27) possible. Storage stays an implementation detail | ADR 0021, `signing.md` |
| OD-22 | Self-test scope: pool or worker | **Approved (owner): every worker is verified individually.** Each worker passes its own self-test for its pool's profile before untrusted builds; the record keeps the configuration digest tested; a change to security-relevant configuration, profile or capabilities invalidates it; scheduled and administrator-triggered retests; pool approval stays separate; failed or outdated tests block the worker. One passing worker never verifies a pool | ADR 0027 (amended), `scheduler-and-workers.md` |
