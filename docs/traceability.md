# Requirements Traceability Matrix

Status: **Living document.** One row per product decision ([`product/decisions.md`](product/decisions.md)).

**Source** describes how a decision is implemented: *native* means original Samuori code; *integration* means an
external OSS component behind a Samuori adapter; *mixed* means both.

**Status:** `specified` (documented, nothing built) → `in progress` → `implemented` (code merged, tests passing) →
`validated` (acceptance tests and evidence linked) or `deferred (owner-approved, link)`.

> All tests were removed on 2026-10-20 and focused regression tests were restored the same day (ADR 0039 as
> amended). Test names and results in this table are history from earlier commits unless the row or
> `developers/security-test-catalog.md` names a current test. "Unverified: tests removed" means the row's own tests
> were not restored.
