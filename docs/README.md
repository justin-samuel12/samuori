# Documentation Index

Authority order when documents disagree (ADR 0002): `product/decisions.md` → accepted ADRs → product and
architecture docs → `CLAUDE.md`. A conflict is a bug; fix it with an ADR in the same change.

All tests were removed on 2026-10-20, and focused regression tests for critical security boundaries and practical
workflows were restored the same day (ADR 0039 as amended). Where a document cites a test, make target or result
that no longer exists, it records a run at an earlier commit, which the current tree cannot reproduce.
