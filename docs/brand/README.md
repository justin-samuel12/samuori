# Samuori brand files

The approved logo, used unchanged (ADR 0057). Each file comes in a light variant for light surfaces and a dark variant
for dark ones.

| File | Use |
|---|---|
| `samuori-flat-logo-*.svg` | Navigation and headers, below 240 px wide |
| `samuori-flat-icon-*.svg` | Favicons and small icons, below 64 px |
| `samuori-flat-stacked-*.svg` | Centred layouts |
| `samuori-3d-logo-*.svg`, `samuori-3d-stacked-*.svg`, `samuori-3d-icon-*.svg` | Large displays such as sign-in and About |
| `tokens.json` | The light and dark semantic colours the UI tokens follow |

Keep the aspect ratio and clear space of at least a tenth of the icon's width. Never crop, recolour, invert or redraw
the files. The wordmark's letters are outlined from DejaVu Sans Bold; keep `DejaVu-font-notice.txt` with any copy you
distribute.
